# つながりの木

## 基準キャンバス
1672 × 941 px

## scene
- `assets/scene/layer-00-distant.png`
- `assets/scene/layer-10-ground.png`
- `assets/scene/layer-20-tree.png`
- `assets/scene/layer-40-foreground.png`

4枚とも1672×941の共通キャンバスで管理します。

## UI方針
景観を壊す看板・ジュークボックス画像は使用しません。

- 「つながりの木」の文字: HTML/CSS
- BGM操作: CSS + inline SVG
- メンバー追加: CSS + inline SVG
- メンバーアイコン: HTML UI
- プロフィールカード: HTML/CSS
- BGM: `assets/audio/bgm.mp3`

パララックスは画像の拡大縮小をせず、各レイヤーを数px平行移動するだけにしています。

## アイコン表示
メンバーアイコンは景観を暗くせず、アイコン自身に半透明の濃色背景・白枠・弱い影を付けて視認性を確保します。

追加時にアイコン形状を選択できます。
- 丸
- 角丸
- 四角

形状選択UIもCSS + inline SVGで構成しています。

## ドラッグ操作修正
メンバーアイコンはマウス・タッチともに直接ドラッグして移動します。
4px未満の移動はタップ/クリックとして扱いプロフィールを開き、4px以上はドラッグとして扱うため誤操作を抑えています。

アイコン背景は余分なpaddingを廃止し、画像と背景の外形・形状を完全に一致させています。

## アイコンサイズ
メンバー追加時に40〜120pxの範囲を2px刻みでスライダー調整できます。
サイズは各メンバーごとに保持され、背景・枠・画像も一緒に拡大縮小されます。


## BGM
3曲選択、再生・一時停止、停止、ミュート、音量調整に対応しています。選択曲と音量はブラウザに保存されます。
